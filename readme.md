# Y-Music-Tools 🎵

Расширение для Яндекс Музыки (Firefox)

![Интерфейс](image/screenshot.png)


##  Основные возможности

### Скачивание
- **MP3 с ID3-тегами и обложкой**, битрейт выбирается в меню: максимум / 320 / 256 / 192 / 128 кбит/с
  - кнопка **«Скачать» у каждой строки** трека в плейлистах и альбомах (при наведении)
  - текущий трек из плеера или из всплывающего окна расширения
  - поиск по названию и скачивание любого трека из базы
  - весь плейлист одним **ZIP** с прогрессом, списком ошибок и остановкой по **Esc**
- **Куда сохранять**: складывать в подпапку с названием плейлиста и/или «спрашивать, куда сохранять» — оба тумблера в подменю «Скачать»

### Плейлисты
- **Статистика**: треки, суммарная длительность, уникальные артисты, топ-10 артистов
- **Экспорт**: копировать названия или ссылки на треки в буфер, скопировать в `.txt` / `.csv` / `.json`
- **Импорт** из файла (`.txt`, `.csv`, `.m3u`, `.m3u8`) — треки ищутся в базе Яндекс Музыки
- **Импорт по ссылке** на трек, альбом или целый плейлист
- **Добавление треков**: поиск и добавление в любой из ваших плейлистов; показывает, сколько из выбранных треков уже есть в каждом из них
- **Даты треков**: дата добавления трека, а если её нет — дата релиза
- **Перейти к треку**: заменяет поиск Яндекса, находит все совпадения по названию, подсвечивает их и листает стрелками

### Волна
- **Скрыть лайки в волне** — убрать из волны все треки из «Мне нравится»
- **Не повторять недавние треки** — треки, сыгранные в любом контексте сайта, больше не подсовываются в волну
  - окно памяти настраивается: 6 / 12 / 24 / 48 часов / 3 дня / неделя
  - **счётчик**: сколько треков скрыто сегодня, с разбивкой на лайки и недавние (сбрасывается в полночь)

### Плеер и качество
- **Качество звука** — превосходное / оптимальное / экономичное, переключается из меню или всплывающего окна

### Приватность
- **Блокировка телеметрии** — режет счётчики Яндекса (Метрика, AppMetrica, Вебмастер, рекламные домены и т.п.), включена по умолчанию

### Интерфейс
- **Меню «Скрыть»** (в меню плейлиста) — выборочно убрать лишнее:
  - навигационные ссылки: «Концерты», «Книги и подкасты», «Ваш Плюс», «Скачать для Windows»
  - разделы коллекции: «Моя волна на двоих», «Любимые альбомы», «Подкасты и книги», «Клипы в коллекции», «Мои дизлайки», «Просмотренные концерты»
  - «Сайдбар по наведению» и «Колесо рекомендаций по наведению»
  - футер с юридической информацией
- **Правки страницы** (применяются всегда):
  - обложки альбомов приводятся к ровному размеру
  - в плеере волны исправляется переставленное название и артист
  - убираются кнопка сброса и декоративный текст на странице волны

### Всплывающее окно расширения
Иконка в панели → название и артист того, что играет сейчас, кнопки «Сохранить трек» и «Сохранить плейлист (ZIP)», переключатель качества звука и быстрые переключатели: даты треков, скрытие лайков в волне, не повторять недавние, блокировка телеметрии.


##  Установка
1. Соберите: `python build.py` (нужен Python 3)
2. Откройте `about:debugging#/runtime/this-firefox`
3. «Загрузить временный дополнитель» → `Y-Music-Tools.zip` (или распакованная папка)

##  Сборка
```bash
python build.py
```

## 🗒️ Примечания
- Полные версии треков требуют подписки Яндекс Плюс / Премиум.
- При скачивании всего плейлиста треки упаковываются в ZIP без сжатия и сохраняются через API браузера — архив целиком собирается в памяти, так что очень большие плейлисты лучше качать частями.
- Одновременно может идти только одна загрузка плейлиста: новая прервёт контроль над отменой предыдущей.
- Список треков плейлиста читается максимум до 4500 треков, лайков — до 3000.
- Настройки хранятся в `localStorage` сайта, поэтому у каждого домена Яндекс Музыки (`.ru`, `.kz`, `.com` и т.д.) они свои.
- Меню расширения доступно на страницах плейлистов и альбомов; на главной странице волны его нет, но все глобальные настройки (скрытие, качество, телеметрия) продолжают работать.
